# ITI — HTML5 Lab 2

This repository contains example HTML5 demos used in the ITI Lab 2 exercises. Each file demonstrates different HTML5 features: SVG, Canvas, animations, gradients, MathML, and basic cookie storage handling.

## Files

- [animation.html](animation.html) — SVG line animation demonstrating stroke-dasharray and the Web Animations API to animate a diagonal line drawing.
- [boxescanvas.html](boxescanvas.html) — Canvas demo showing gradients, filled rectangles and stroked lines to form box shapes.
- [boxeswithsvg.html](boxeswithsvg.html) — SVG layout of stacked boxes and internal guide lines (pure SVG shapes).
- [cookie.html](cookie.html) — Simple UI to save/find/delete key/value pairs using the cookie helper library. Uses `cookielib.js` for storage functions.
- cookielib.js / cookie.js — helper scripts for reading/writing cookies (one is a minimal stub in the demos; `cookie.html` references `cookielib.js`).
- [mathml.html](mathml.html) — MathML example (Pythagoras theorem) alongside an SVG triangle illustration.
- [Nshape.html](Nshape.html) — Canvas example drawing gradients and a centered letter "N" using conic/radial gradients.

## Prerequisites

- Modern web browser (Chrome, Firefox, Edge) with HTML5 support.

## How to run

- Open any of the `.html` files directly in your browser (double-click or use `Open File` in the browser).
- For the cookie demo, use [cookie.html](cookie.html) which loads `cookielib.js` from the same folder.

## Notes

- Filenames include a small typo: `animation.html` (animation demo). Keep the filename as-is or rename if you prefer.
- `cookie.js` in other demo folders may be a stub; `cookie.html` expects `cookielib.js` included in this folder.
